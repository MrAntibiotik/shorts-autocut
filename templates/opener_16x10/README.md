# Універсальний opener MR_ANTIBIOTIK — 16:10 (2560×1600, 60 fps)

## Як працює
Підставляєш від 3 до 6 моментів у потрібному порядку — шаблон сам підлаштовує тривалість, склейки і музику:
- **1-й момент — HOOK** (2 с): удар і спалах на старті, zoom-punch.
- **Середні моменти** (по 2,5 с): whoosh, глітч і спалах на кожній склейці.
- **Останній момент — ПІК** (2,5 с): райзер, стоп-пауза, дроп, червоний пульс рамки, freeze-frame в останні 0,5 с.
- **Заставка** (3 с): MR_ANTIBIOTIK розгорається з мерехтінням екрану, світиться і гасне.

| Моментів | Довжина opener'а |
|---|---|
| 3 | 10 с |
| 4 | 12,5 с |
| 5 | 15 с |
| 6 | 17,5 с |

Темп 120 BPM — усі склейки точно в біт.

## Файли
- `hud_16x10.webm` — HUD: кутові рамки, REC, таймкод, віньєтка (з прозорістю)
- `hit_16x10.webm` — перехід на склейці (з прозорістю)
- `peak_16x10.webm` — ефект піку (з прозорістю)
- `outro_16x10.mp4` — заставка з нікнеймом
- `music_3.wav` … `music_6.wav` — музика під кожну кількість моментів
- `template.json` — тривалості, гучність, підписи (редагується без коду)
- `fill_template.py` — збирає opener; `gen_template.py` — перегенерувати ассети

## Встановлення (Windows)
1. Python 3.9+ (галочка «Add to PATH»).
2. ffmpeg (збірка gyan.dev «full»), папку `bin` — у PATH.
3. Лише для `gen_template.py`: `pip install pillow numpy scipy`.

## Запуск
`python fill_template.py moments.json` (або `run_example.bat`). NVENC вмикається автоматично.

## moments.json (формує твоя програма)
```json
{
  "output": "opener.mp4",
  "moments": [
    {"src": "D:/stream.mp4", "start": 1834.2},
    {"src": "D:/stream.mp4", "start": 412.0},
    {"src": "D:/stream.mp4", "start": 2201.3}
  ]
}
```
- Порядок у списку = порядок в opener'і: перший — HOOK, останній — ПІК.
- `start` — секунда початку у вихідному відео (бери ~0,5 с ДО піку моменту).
- Потрібна довжина від `start`: HOOK 2 с, середні 2,5 с, ПІК 2 с.
- `volume` (опційно) — гучність звуку конкретного моменту, напр. `0.7`.
- Підписи вимкнені. Щоб увімкнути: `"captions": true` і в кожному моменті `"caption": "ТЕКСТ"` (до 22 символів).
- Відео будь-якого розміру/fps автоматично підганяється під 2560×1600.
- `canvas` (опційно) — інший розмір кадру 16:10, напр. `{"width": 2304, "height": 1440}` (під запис гри): HUD, переходи, пік, заставка й підписи масштабуються самі. Автонарізка передає сюди розмір хайлайту.

## Своя музика
Заміни `music_N.wav` треком 120 BPM потрібної довжини (див. таблицю): дроп — на початку ПІКу, удар — на початку заставки.
