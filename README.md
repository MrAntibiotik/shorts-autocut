# Автонарізка шортсів зі стрімів (World of Tanks, PUBG, STALKER 2…)

Інструмент сам знаходить у записі стріму найкращі моменти і збирає з кожного бою вертикальний шортс
1080×1920, 60 fps:
- **таймлайн у DaVinci Resolve 21** (безкоштовна версія), який можна підправити вручну;
- **готовий MP4.**

Усе працює локально на вашому ПК з відеокартою NVIDIA, без хмарних сервісів і платних API.

---

## Встановлення — 3 кроки

1. **Завантажте файл `SETUP.bat`.** Відкрийте <https://github.com/MrAntibiotik/shorts-autocut/blob/main/SETUP.bat>
   і натисніть кнопку **Download raw file** (стрілка вниз над текстом файлу).
2. **Двічі клацніть `SETUP.bat`.** Якщо Windows покаже «Windows захистив ваш ПК», натисніть **Докладніше → Усе одно запустити**.
   Далі все піде саме, 15–45 хв. Установник:
   - перевірить драйвер NVIDIA і, якщо він старіший за 570, відкриє сторінку оновлення;
   - поставить Python 3.11;
   - завантажить інструмент у `C:\ShortsTool`, ffmpeg і бібліотеки (PyTorch з CUDA, Demucs, EasyOCR);
   - поставить кнопку в DaVinci і ярлик **«Автонарізка шортсів»** на робочий стіл;
   - наприкінці все перевірить.
3. **Повністю закрийте й знову відкрийте DaVinci Resolve.**

**Оновлення:** запустіть `SETUP.bat` ще раз (він лежить і в `C:\ShortsTool`). Ваші рамки, налаштування,
зразки звуків і готові шортси при оновленні зберігаються.

---

## Як користуватися

1. Відкрийте DaVinci (будь-який проєкт). Якщо в медіапулі виділити запис, він підставиться у вікно сам.
   Шортси кнопка збере в окремому новому проєкті «Шортси <дата>» — так DaVinci гарантовано робить таймлайни 1080×1920, 60 fps.
2. Натисніть **Workspace → Scripts → Shorts Autocut**. Відкриється вікно запуску:
   - **Запис(и)** — «Додати…» (можна кілька файлів);
   - **Профіль гри** — World of Tanks / PUBG / S.T.A.L.K.E.R. 2;
   - **Відрізок** — необов'язково, наприклад `1:00:00` – `1:20:00`. Для першої спроби візьміть 15–30 хв;
   - **Заклик у кінці шортсу** — текст на останні 3 с. Останній текст запам'ятовується; порожньо — без заклику;
   - **галочки:** рендер MP4, відділення голосу від гри. Субтитри — експериментально, за замовчуванням вимкнені.
3. **Почати.** Обробка йде у вікні з прогресом, DaVinci при цьому вільний. Можна зупинити — готові частини збережуться.
4. Коли вікно напише **«Готово»**, натисніть **Workspace → Scripts → Shorts Autocut** ще раз — зберуться таймлайни.

> Можна обходитись і без DaVinci: ярлик «Автонарізка шортсів» на робочому столі відкриває те саме вікно.
> Готові MP4 будуть у папці результату.

### Перший запуск для гри — рамки
Вікно запуску спитає, чи обвести рамки. Відкриється **одне вікно**: ліворуч кадр з вашого запису, праворуч список.

Для **World of Tanks** — 4 рамки:

| Рамка | Що обводити |
|---|---|
| **Вебкамера** | усю вебкамеру в кадрі гри |
| **Блок лічильників** | три рядки «шкода / заблоковано / допомога» з іконками (зліва внизу), із запасом праворуч під 5 цифр |
| **Повідомлення про шкоду** | рядок посередині екрана «941 ✕ Шкода пострілом ◆ Progetto 65», з запасом по ширині |
| **Таймер бою** | час у правому верхньому куті («12:47») |

Для **PUBG** і **S.T.A.L.K.E.R. 2** — лише вебкамера.

Рамки WoT за замовчуванням уже виставлені за вашим скріном. Подивіться, чи кожна стоїть на своєму елементі,
і натисніть **«Зберегти»**. Щоб переобвести, виберіть зону в списку і обведіть мишкою.

Повідомлення про шкоду видно не на кожному кадрі. Щоб його побачити, внизу праворуч введіть секунду,
де ви влучили, і натисніть «Показати». Уже обведені рамки при цьому не зникають.
Це робиться один раз для гри. Переобвести пізніше можна через `extra\pick_zones.bat`.

## Що виходить у результаті

**У DaVinci** — окремий новий проєкт **«Шортси <дата>»** (1080×1920, 60 fps; ваш поточний проєкт перед цим
зберігається). У медіапулі — окрема підпапка на кожен бій («Бій 01 — шкода 3837», «Бій 03 — засвіт 2650»…):
- таймлайн **«<запис> — моменти»** з кольоровими маркерами всіх знайдених моментів:
  - зелений — влучання (у назві маркера — шкода);
  - червоний — отримана шкода;
  - фуксія — вас знищено;
  - блакитний — ваша емоція;
  - синій — звук гри;
- у папці кожного бою — таймлайн **«Шортс NN — бій …»** 1080×1920, 60 fps:
  - **V1** — гра (центральна частина кадру на весь екран);
  - **V2** — вебкамера, вікно 640×410 зверху по центру;
  - **V3** — блок лічильників (WoT), зліва посередині;
  - **V4** — заклик (титр Text+; якщо DaVinci не дозволяє вставити титр скриптом — картинка з текстом);
  - **A1** — звук.

  Рамки задані через **Zoom / Position / Crop** в Inspector.

**На диску** — `C:\ShortsTool\output\job_<дата>\`, кожен бій в окремій папці:
```
job_20261110_201500\
  battle_01_dmg_3837\
    <запис>_battle_01.mp4   готовий шортс (H.264 NVENC, 1080×1920, 60 fps, із закликом)
    cta.txt                 текст заклику (для повторного рендеру)
    moments.csv             моменти цього бою
  battle_03_assist_2650\  …  (бої без вартих моментів пропускаються)
  <запис>_report.csv        загальний звіт: бій, час, тип події, шкода, score, джерело, у який шортс потрапило
  <запис>_markers.edl       маркери для DaVinci (ПКМ по таймлайну в медіапулі → Timelines → Import → Timeline Markers from EDL)
```
Номер папки — це номер бою в записі. Після номера — більша з двох величин бою: **шкода** (`dmg`) або **засвіт** (`assist`).
Обидві беруться з блоку лічильників, заблокована шкода теж іде у звіт.
Назви папок латиницею, бо кнопка DaVinci не відкриває шляхи з кирилицею.

## Як відбираються моменти (World of Tanks)

- **Бій** — межі **лише за таймером** праворуч угорі. Усе поза боєм (ангар, результати) відкидається:
  - **початок** — таймер стоїть на цілій хвилині (15:00, а буває 20:00 чи 10:00) **довше 5 с**. Це відлік перед боєм;
  - **кінець** — таймер зник довше 30 с. Бій може закінчитися будь-коли, за 3 хв чи за 15;
  - якщо таймер ненадовго ховався (велика карта, таблиця) і повернувся з тим самим відліком — бій той самий;
  - якщо запис почався посеред бою, перший бій визначається за таймером, що вже йде.

  **Один бій = одна папка = один шортс до 60 с.**
- **Момент = повідомлення про вашу шкоду** посередині екрана: «1 537 ✕ Шкода пострілом» **зеленим**.
  - Червоні рядки (шкода по вас) моментами не є.
  - Шкоду і підсумок бою підтверджує лічильник у блоці зліва внизу.
  - Шкода до 100 (пожежа, таран) моментом не вважається.
- **Запас — 3 с до і 6 с після пострілу.** Якщо ви ще говорите чи реагуєте, кінець подовжується до паузи у вашій мові,
  але не більше ніж на 6 с. Початок зсувається на паузу в мові до 1,5 с, щоб не різати фразу.
  Ваш голос відділяється від звуку гри нейромережею.
- **Ваша реакція** (крик, сміх, сплеск гучності) протягом 3 с після пострілу підсилює момент.
- **Близькі постріли** зливаються в один шматок.
- **Ваша смерть** (екран «Оцініть бій») — фінальний момент, включається завжди.
- **Якщо все не влазить у 60 с,** беруться найсильніші моменти (шкода + ваша реакція) і ставляться по порядку часу.
- **Назва папки бою** — за більшою з величин блоку лічильників: `battle_03_dmg_3837` або `battle_04_assist_2650`.

Для PUBG і S.T.A.L.K.E.R. 2 зорових підказок немає: моментами є гучні звуки гри (постріли, вибухи) і ваші реакції.
Матчі розділяються за паузами між скупченнями подій.

## Правки після обробки

- **Межі моменту в DaVinci.** Кліпи кожного шматка (V1, V2, V3, A1) **зв'язані**:
  - тягніть край будь-якого кліпу — зсунуться всі чотири;
  - Delete / Shift+Delete прибирає шматок цілим;
  - можна тягнути назовні, щоб додати секунди.
- **Рамка одного шару** (наприклад, Zoom камери): клацніть по кліпу з **Alt**, інакше Inspector змінить усі виділені.
- **Пропущений момент** легко знайти на таймлайні «… — моменти» (маркери) і скопіювати в шортс.
- **Готові MP4 без DaVinci:** змініть текст заклику в `cta.txt` у папці бою, перетягніть папку
  `output\job_…` на `extra\rerender.bat` і вкажіть номери шортсів.

## Налаштування (без правки коду)

Файли можна правити Блокнотом. Ключі, що починаються з `_`, — пояснення. Попередня версія профілю зберігається як `.json.bak`.

**Скинути налаштування гри:** у вікні запуску кнопка **«Скинути налаштування…»** поруч із профілем гри
(або `extra\reset_profile.bat`). «Так» — повернути стандартні налаштування, залишивши ваші рамки;
«Ні» — скинути все разом із рамками. Попередня версія зберігається як `.json.bak`.

**`config\profiles\wot.json`** (і аналогічні для інших ігор):
- `selection.pre_s` / `post_s` — запас до/після моменту (зараз 3 с / 6 с);
- `selection.snap_after_max_s` — на скільки ще можна подовжити кінець, поки ви говорите (6 с);
- `selection.merge_gap_s` — коли близькі моменти зливаються (4 с);
- `selection.max_duration_s` — найдовший шортс (60 с);
- `selection.min_score` — наскільки сильним має бути момент;
- `selection.speech_snap` / `snap_max_s` — підгонка під паузи в мові;
- `layout.overlay` — вікно вебкамери: `webcam_x`, `webcam_y`, `webcam_width`, `webcam_height`;
  `webcam_fit` — `cover` заповнює вікно, `contain` показує камеру цілою;
- `layout.counters` — блок лічильників:
  - `anchor`: `left_middle` (зліва посередині), `right_middle`, `below_webcam`, `absolute`;
  - `height` — розмір блоку, `margin` — відступ від краю, `offset_y` — зсув вгору/вниз;
- `layout.cta_y` — висота заклику;
- `vision.*` — пороги розпізнавання.

**`config\settings.json`:**
- `recording.mode` — `mixed` (зараз: одна звукова доріжка, вебкамера в кадрі) або `separate`
  (окремі доріжки гри й мікрофона та окремий файл вебкамери з OBS Source Record);
- `separation.enabled` — відділяти голос від гри;
- `render` — якість MP4;
- `cta` — тривалість заклику (3 с) і розмір шрифту;
- `resolve` — кольори маркерів, `link_clips` (зв'язувати кліпи шматка), `project_mode`
  (`new` — окремий проєкт для шортсів, рекомендовано; `current` — у поточному проєкті).

## Експеримент: розумне розпізнавання мови (вимкнено за замовчуванням)

Замість «голосно = говорить» — нейромережа **Silero VAD** (розрізняє саме мову, а не шум/гру/дихання)
і **faster-whisper** (текст і час кожного слова). Що дає:

- **повні фрази** — якщо шматок шортсу обривається посеред вашого речення, він продовжується до його
  кінця (до 5 с), а початок — до початку фрази (до 2 с), у межах 60 с;
- **кращі субтитри** — розпізнається ширше вікно навколо моментів (з контекстом), а не склеєні обрізки.

Як спробувати:
1. `extra\setup_speech_ai.bat` — ставить бібліотеки і модель (large-v3, ~3 ГБ), сам перевіряє відеокарту.
2. `extra\test_speech.bat` — перетягніть запис, вкажіть відрізок 2–10 хв. У `output\reports\` з'являться
   `*_speech.txt` (фрази з часом + порівняння старого і нового визначення мови) і `*_speech.srt`
   (субтитри — відкрийте разом із записом у плеєрі).
3. Подобається — галочка **«Розумне розпізнавання мови»** у вікні запуску.

Якщо щось піде не так, у лозі буде `[УВАГА]`, а обробка продовжиться старим способом. Налаштування —
розділ `speech_ai` у `config\settings.json`.

## Якщо щось не працює

| Що сталося | Що зробити |
|---|---|
| `SETUP.bat` зупинився з `[ПОМИЛКА]` | Надішліть текст з вікна; після виправлення запустіть `SETUP.bat` ще раз |
| У Workspace → Scripts немає кнопок | Повністю перезапустіть DaVinci; якщо не допомогло — `extra\install_resolve.bat` |
| Кнопка нічого не робить | Workspace → Console покаже помилку; лог — `C:\ShortsTool\work\logs\resolve_import.log`. Обробку можна запустити ярликом на робочому столі, а потім натиснути кнопку для імпорту |
| Рамки на таймлайні не там (V2 показує не камеру) | Надішліть скриншот і `resolve_import.log`. Тимчасово: `settings.json → resolve.mismatch_mode` (`fit` / `fill`), потім **Workspace → Scripts → Shorts Reimport Last** |
| Влучання не знаходяться | `extra\test_vision.bat` на відрізку з боєм → у `output\debug\…` видно, що розпізнано. Якщо рамка не на місці — `extra\pick_zones.bat` |
| `CUDA недоступна` | Оновіть драйвер NVIDIA (570+), перезавантажте ПК, запустіть `SETUP.bat` ще раз |
| Програма почала працювати дивно або закінчується місце на диску | Кнопка **«Очистити кеш…»** у вікні запуску (або `extra\clear_cache.bat`). Шортси, налаштування й рамки не видаляються; наступний запуск буде довшим |
| Помилка в JSON після ручної правки | Виправте вказаний рядок або поверніть файл `.json.bak` |

Логи всіх запусків — у `C:\ShortsTool\work\logs\`.

## Як влаштовано всередині

```
SETUP.bat, setup.ps1          встановлення / оновлення
config\settings.json          загальні налаштування
config\profiles\<гра>.json    профіль гри: рамки, пороги, відбір, макет
resolve\shorts_lib.lua        кнопка в DaVinci (Lua): запуск обробки, збирання таймлайнів
shorts\vision_detector.py     розпізнавання екрану: лічильники, повідомлення про шкоду, таймер, екран смерті
shorts\audio.py               витяг звуку, розділення голос/гра (Demucs)
shorts\audio_detector.py      звуки гри (зразки, гучні звуки)
shorts\voice_detector.py      ваш голос: сплеск, крик, сміх
shorts\fusion.py              об'єднання сигналів і сила моменту (score)
shorts\selection.py           бій -> шортс до 60 с, підгонка під паузи в мові
shorts\layout.py              макет кадру (спільний для DaVinci і MP4)
shorts\render.py, textimg.py  рендер MP4 (NVENC), текст заклику
shorts\pipeline.py            повний цикл обробки
shorts\subtitles.py           субтитри whisper.cpp (експериментально)
tools\                        вікна і службові скрипти (запуск, рамки, перевірки)
extra\                        .bat-файли додаткових інструментів
```

Оригінальні записи тільки читаються, нічого не змінюється. Довгі записи (4–8 год) обробляються частинами по 10 хв,
тож пам'ять не переповнюється. Уже оброблені частини кешуються в `work\` — повторний запуск іде швидше.

**Автоприбирання `work\`.** Після зміни рамок чи налаштувань старий кеш запису вже не підходить —
його видаляє одразу (перший запуск після цього йде повністю, наступні — знову швидко). Кеш інших
записів, тимчасові файли завдань і логи видаляються, якщо ними не користувались довше 14 днів.
Оригінали й готові шортси (`output\`) не чіпаються. Налаштування — `cleanup` у `config\settings.json`
(`keep_days` — скільки днів зберігати, `enabled: false` — вимкнути).

### Ручне встановлення (лише якщо SETUP.bat не спрацював)
1. Встановіть Python 3.11 (64-bit) з <https://www.python.org/downloads/windows/>, з галочкою «Add python.exe to PATH».
2. Завантажте <https://github.com/MrAntibiotik/shorts-autocut/archive/refs/heads/main.zip>
   і скопіюйте вміст папки `shorts-autocut-main` у `C:\ShortsTool`.
3. Завантажте `ffmpeg-master-latest-win64-gpl.zip` з <https://github.com/BtbN/FFmpeg-Builds/releases/latest>
   і розпакуйте в `C:\ShortsTool\ffmpeg`.
4. Запустіть `extra\install.bat`, потім `extra\install_resolve.bat`, перезапустіть DaVinci.
